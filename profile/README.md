# Infinite Labs AI

We build open-source growth tools and agent skills around Infinite, a governed growth engine for founders.

## Start here

- [Download Infinite for Mac](https://infinite.fast/download) — the canonical Apple-silicon desktop download.
- [Install Infinite OS](https://github.com/Infinite-Labs-AI/infinite-os#quickstart) — MIT-licensed local engine and CLI for Claude or Codex.
- [Install Infinite Skills](https://github.com/Infinite-Labs-AI/infinite-skills#install-for-codex) — 25 marketing skills plus the Goal skill for Codex.
- [Run Press Agent](https://github.com/Infinite-Labs-AI/infinite-press-agent) — local-first Qwoted opportunity scanning and pitching. Use dry-run when you do not want pitches submitted.

Website: [infinite.fast](https://infinite.fast/) · Agent ecosystem: [infinite.fast/agents](https://infinite.fast/agents/) · [Security](https://github.com/Infinite-Labs-AI/.github/security/policy)

## More open-source projects
